**遇到的坑（重要）**：
1. **本机安全策略禁止 `schtasks.exe`** → 无法用计划任务让隧道常驻
2. **Bash 工具禁止调用 `cmd.exe`**（"bypasses all command validation"）
3. 后台进程（`&` / `nohup` / `cmd start`）**无法在 shell 会话结束后存活** → cloudflared 隧道反复中断
4. PowerShell 工具在此环境下**不返回 stdout**（`Write-Output` 拿不到），只能靠 Bash 侧验证
5. Cloudflare quick tunnel 用 QUIC 协议首次拨号超时，改用 `--protocol http2` 才注册成功
6. **quick tunnel 地址每次重启都变**，且边缘路由有生效延迟，测试中出现 1033 错误页
