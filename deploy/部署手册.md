# RAG 技术知识库问答系统 — 部署手册

> 目标机器：阿里云 ECS（Alibaba Cloud Linux 3.2104），x86_64，2核 / 1.8G 内存 / 40G 磁盘
> 部署架构：**服务器只跑 Web 应用（FastAPI + MySQL + Nginx），大模型推理放在你本机 Ollama，经 Cloudflare 隧道连通**
> 前端：使用 **RAG-** 仓库的**用户端**（`dist-user`）

---

## 0. 项目结构说明

本项目由**两个仓库**组成：

| 仓库 | 角色 | 地址 |
|---|---|---|
| `RAG-----` | **后端**（FastAPI）+ 部署材料 | `https://github.com/jdsis/RAG-----.git` |
| `RAG-` | **前端**（Vue3，双入口） | `https://github.com/jdsis/RAG-.git` |

两者均为公开仓库，**clone 无需 Token**。

**RAG- 前端有两个入口**（同一套代码，构建时通过 `--mode` 区分）：
- `npm run build:user` → `dist-user/`（用户端）← **本次部署这个**
- `npm run build:admin` → `dist-admin/`（管理端，本次不部署）

## 1. 架构总览

```
┌─────────────────────┐          ┌───────────────────────────────┐
│   Ollama 所在机器    │          │   阿里云 ECS (2C1.8G)          │
│                     │          │                               │
│  Ollama :11434      │◀─────────│  FastAPI :8000 (systemd)      │
│  qwen3:8b           │  HTTPS   │    ├── MySQL :3306            │
│  qwen3-embedding    │  隧道     │    └── Chroma (本地文件)       │
│          ▲          │          │                               │
│          │          │          │  Nginx :80                    │
│  cloudflared 隧道    │          │    ├── / → dist-user 静态文件   │
│                     │          │    ├── /api → 反代 :8000       │
└─────────────────────┘          │    └── /uploads → 本地上传目录   │
                                 └───────────────────────────────┘
                                              ▲
                                              │ 经 Cloudflare 隧道访问
                                         用户浏览器
```

**重要前提**：Ollama 所在机器必须**一直开机**，且隧道保持运行。该机停机 = 问答功能失效（登录、文档管理等不受影响）。

## 2. 前置条件确认

部署前请确认以下信息（下文用占位符表示）：

| 占位符 | 含义 | 示例 |
|---|---|---|
| `<OLLAMA_URL>` | Ollama 的公网访问地址 | `https://ollama.example.com` |
| `<DB_PASS>` | 数据库密码（第 4 步生成） | 脚本自动生成 |
| `<JWT_SECRET>` | 鉴权密钥（第 4 步生成） | 脚本自动生成 |

**验证 Ollama 可达**（在服务器上执行）：

```bash
curl -m 20 https://<OLLAMA_URL>/api/version
# 期望：{"version":"0.40.0"}
```

> ⚠️ 这一步不通，后面的问答功能一定不可用。先解决它。

## 3. 服务器初始化

**全部以 root 执行。**

### 3.1 更新系统

```bash
dnf upgrade-minimal --security -y
```

### 3.2 安装依赖软件

```bash
dnf install -y python3.11 python3.11-devel python3.11-pip \
               gcc gcc-c++ make git nginx mysql-server \
               tesseract tesseract-langpack-chi_sim poppler-utils
```

### 3.3 启动 MySQL

```bash
systemctl enable --now mysqld
systemctl status mysqld --no-pager
```

### 3.4 创建目录

```bash
mkdir -p /opt/rag-kb/{data/chroma,data/uploads,logs}
mkdir -p /opt/rag-kb-app
```

> `/opt/rag-kb` 存运行数据，`/opt/rag-kb-app` 存代码，两者分开便于备份和更新。

## 4. 创建数据库

```bash
DB_PASS=$(openssl rand -base64 18 | tr -d '/+=' | head -c 24)
echo "======================================"
echo "数据库密码（请抄下来）：$DB_PASS"
echo "======================================"

mysql -uroot <<SQL
CREATE DATABASE IF NOT EXISTS rag_kb DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'rag'@'127.0.0.1' IDENTIFIED BY '${DB_PASS}';
ALTER USER 'rag'@'127.0.0.1' IDENTIFIED BY '${DB_PASS}';
GRANT ALL PRIVILEGES ON rag_kb.* TO 'rag'@'127.0.0.1';
FLUSH PRIVILEGES;
SQL
```

生成 JWT 密钥：

```bash
python3.11 -c "import secrets; print(secrets.token_urlsafe(48))"
```

> **把这两个值抄下来**，下一步要用。

## 6. 配置后端

### 6.1 建虚拟环境装依赖

```bash
cd /opt/rag-kb-app/backend
python3.11 -m venv venv
venv/bin/pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
venv/bin/pip install --upgrade pip
venv/bin/pip install -r requirements.txt
```

> 若 `chromadb` / `tokenizers` 编译失败，见「常见问题」第 4 条。

### 6.2 写入 .env

```bash
cat > /opt/rag-kb-app/backend/.env <<'EOF'
DATABASE_URL=mysql+pymysql://rag:CHANGE_ME_DB_PASS@127.0.0.1:3306/rag_kb?charset=utf8mb4
OLLAMA_BASE_URL=CHANGE_ME_OLLAMA_URL
CHAT_MODEL=qwen3:8b
EMBEDDING_MODEL=qwen3-embedding:0.6b
OLLAMA_TIMEOUT_SECONDS=60
ALLOW_PRIVATE_MODEL_URLS=false
CHROMA_DIR=/opt/rag-kb/data/chroma
UPLOAD_DIR=/opt/rag-kb/data/uploads
JWT_SECRET_KEY=CHANGE_ME_JWT_SECRET
CORS_ORIGINS=http://CHANGE_ME_YOUR_HOST
MAX_UPLOAD_BYTES=52428800
MAX_AVATAR_BYTES=2097152
MAX_WEB_PAGE_BYTES=2097152
SMTP_HOST=smtp.163.com
SMTP_PORT=465
SMTP_USERNAME=CHANGE_ME_YOUR_EMAIL
SMTP_PASSWORD=CHANGE_ME_SMTP_AUTH_CODE
SMTP_FROM_EMAIL=CHANGE_ME_YOUR_EMAIL
SMTP_FROM_NAME=技术知识库问答系统
SMTP_USE_SSL=true
SMTP_USE_TLS=false
CHUNK_SIZE=600
CHUNK_OVERLAP=100
TOP_K=5
EOF

chmod 600 /opt/rag-kb-app/backend/.env
```

**编辑这个文件，把 4 个 `CHANGE_ME_*` 换成实际值：**
```bash
vi /opt/rag-kb-app/backend/.env
```
- `CHANGE_ME_DB_PASS` → 第 4 步的数据库密码
- `CHANGE_ME_OLLAMA_URL` → 你的 Ollama 地址（不带末尾斜杠）
- `CHANGE_ME_JWT_SECRET` → 第 4 步生成的密钥
- `CHANGE_ME_YOUR_HOST` → 服务器访问地址（用隧道域名的话填该域名）

### 6.3 试跑验证

```bash
cd /opt/rag-kb-app/backend
venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

看到 `Application startup complete` 后，**另开终端**：

```bash
curl http://127.0.0.1:8000/
# 期望：{"message":"RAG Knowledge Base API","docs":"/docs"}
```

成功则 `Ctrl+C` 停掉。

## 8. systemd 托管后端

```bash
cat > /etc/systemd/system/rag-kb.service <<'EOF'
[Unit]
Description=RAG Knowledge Base API
After=network.target mysqld.service

[Service]
Type=simple
WorkingDirectory=/opt/rag-kb-app/backend
Environment="PATH=/opt/rag-kb-app/backend/venv/bin"
ExecStart=/opt/rag-kb-app/backend/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
Restart=always
RestartSec=5
StandardOutput=append:/opt/rag-kb/logs/app.log
StandardError=append:/opt/rag-kb/logs/app.error.log

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now rag-kb
systemctl status rag-kb --no-pager
```

> `--workers 1`：机器内存小，多 worker 会 OOM，且项目内的解析线程模型要求单进程。

## 9. Nginx 配置

```bash
cat > /etc/nginx/conf.d/rag-kb.conf <<'EOF'
server {
    listen 80 default_server;
    server_name _;

    # 用户端静态文件
    root /opt/rag-kb-app/frontend/dist-user;
    index index.html;

    # Vue Router history 模式回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反代
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 流式问答必需：关闭缓冲
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
        chunked_transfer_encoding on;
    }

    # 上传文件访问
    location /uploads/ {
        alias /opt/rag-kb/data/uploads/;
    }

    client_max_body_size 60m;
}
EOF

rm -f /etc/nginx/conf.d/default.conf 2>/dev/null
nginx -t
systemctl enable --now nginx
systemctl reload nginx
```

放行防火墙：

```bash
firewall-cmd --permanent --add-service=http
firewall-cmd --reload
```

## 10. 对外访问（服务器无公网 IP 方案）

**⚠️ 本服务器没有公网 IP（控制台显示"公网 IP：-"，带宽 0 Mbps），必须用 Cloudflare 隧道对外发布。**

### 10.1 服务器装 cloudflared

```bash
# 下载（x86_64）
curl -L -o /usr/local/bin/cloudflared \
  https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
chmod +x /usr/local/bin/cloudflared
cloudflared --version
```

### 10.2 登录并创建隧道

```bash
cloudflared tunnel login
```
> 会输出一个 URL，复制到浏览器打开并授权（选择你的域名）。

```bash
cloudflared tunnel create rag-web
```
> 记下输出的 Tunnel ID。

### 10.3 配置

```bash
mkdir -p /root/.cloudflared
cat > /root/.cloudflared/config.yml <<'EOF'
tunnel: rag-web
credentials-file: /root/.cloudflared/<TUNNEL_ID>.json

ingress:
  - hostname: rag.你的域名.com
    service: http://127.0.0.1:80
  - service: http_status:404
EOF
```
> 把 `<TUNNEL_ID>` 和 `rag.你的域名.com` 换成实际值。

### 10.4 创建 DNS 路由

```bash
cloudflared tunnel route dns rag-web rag.你的域名.com
```

### 10.5 装成系统服务

```bash
cloudflared service install
systemctl enable --now cloudflared
systemctl status cloudflared --no-pager
```

### 10.6 验证

浏览器打开 `https://rag.你的域名.com`，应看到登录页。

## 14. 常见问题

**1. 网页 502 Bad Gateway**
后端没起来。`systemctl status rag-kb` + `tail /opt/rag-kb/logs/app.error.log`。多为 `.env` 数据库密码错或 MySQL 未启动。

**2. `Access denied for user 'rag'`**
```bash
mysql -uroot -e "ALTER USER 'rag'@'127.0.0.1' IDENTIFIED BY '新密码'; FLUSH PRIVILEGES;"
# 同步改 .env 里的 DATABASE_URL
```

**3. 问答无响应**
隧道不通。服务器上 `curl <OLLAMA_URL>/api/version` 验证。

**4. pip 装 chromadb / tokenizers 失败**
```bash
dnf install -y gcc gcc-c++ python3.11-devel
venv/bin/pip install --upgrade pip setuptools wheel
venv/bin/pip install --only-binary=:all: tokenizers==0.15.2
```

**5. 进程被 killed（OOM）**
加 swap：
```bash
dd if=/dev/zero of=/swapfile bs=1M count=2048
chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
free -h
```

**6. 前端页面空白 / 404**
确认 `dist-user` 构建成功：`ls /opt/rag-kb-app/frontend/dist-user/` 应有 `index.html` 和 `assets/`。

**7. cloudflared 无法下载**
国内网络问题，可改用镜像或手动下载后 scp 上传。

## 15. 安全清单

- [ ] 服务器 root 密码若曾泄露，立即修改
- [ ] 改用 SSH 密钥登录，关闭密码登录
- [ ] `.env` 权限 `600`
- [ ] JWT 密钥使用随机值
- [ ] 邮箱授权码若泄露，去邮箱后台重置
- [ ] Ollama 暴露的公网地址加访问限制（Cloudflare Access IP 白名单）
- [ ] 管理端如需上线，务必限制访问来源
