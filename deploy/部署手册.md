# RAG 技术知识库问答系统 — 部署手册（方案 A）

> 目标机器：阿里云 ECS，Alibaba Cloud Linux 3.2104 (OpenAnolis)，x86_64，2核 / 1.8G 内存 / 40G 磁盘  
> 部署架构：**服务器只跑 Web 应用（FastAPI + MySQL + Nginx），大模型推理放在你本机的 Ollama，经 Cloudflare 隧道连通**

---

## 0. 架构总览

```
┌─────────────────────┐          ┌───────────────────────────────┐
│   你的 Windows 本机   │          │   阿里云 ECS (2C1.8G)          │
│                     │          │                               │
│  Ollama :11434      │◀─────────│  FastAPI :8000 (systemd)      │
│  qwen3:8b           │  HTTPS   │    ├── MySQL :3306            │
│  qwen3-embedding    │  隧道     │    └── Chroma (本地文件)       │
│          ▲          │          │                               │
│          │          │          │  Nginx :80                    │
│  cloudflared 隧道    │          │    ├── / → 前端静态文件         │
│  xxx.trycloudflare  │          │    └── /api → 反代 127.0.0.1:8000│
└─────────────────────┘          └───────────────────────────────┘
                                              ▲
                                              │ http://公网IP
                                         用户浏览器
```

**重要前提**：你本机必须**一直开机**，且隧道进程保持运行。本机关机 = 问答功能失效（其他功能如登录、文档管理不受影响）。

## 1. 本机侧：启动 Cloudflare 隧道（Windows）

### 1.0 ⚠️ 关于「常驻」的重要说明

**这一步是整个方案 A 的命门**：隧道进程一旦停止，服务器上的问答功能立刻失效。

本机已安装 `cloudflared`（`C:\Program Files (x86)\cloudflared\cloudflared.exe`）。

**推荐做法：把 cloudflared 装成 Windows 服务**（需要管理员权限的 PowerShell / CMD）：

```powershell
# 以管理员身份运行 PowerShell
# 1) 先登录 Cloudflare（浏览器会弹出授权，免费账号即可）
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel login

# 2) 创建命名隧道（地址固定不变，不会每次重启都换）
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel create rag-ollama

# 3) 配置路由：把域名绑到本机 Ollama
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel route dns rag-ollama ollama.你的域名.com

# 4) 装成系统服务（开机自启、崩溃自动重启）
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" service install
```

> 命名隧道需要一个你自己的域名托管在 Cloudflare（免费套餐即可），换来的是**固定地址 + 系统级常驻**，强烈推荐。

**临时做法（不想折腾域名时）**：双击项目根目录的 `start-tunnel.bat`。

> 注意：普通后台启动的进程在 shell 会话结束时可能被回收，导致隧道中断。请**保持该窗口不要关闭**。  
> 本机安全策略禁止了 `schtasks`，所以我无法帮你自动注册计划任务，需要你手动保持窗口或改用上面的系统服务方式。

### 1.1 启动隧道（临时方式）

它的内容是：

```bat
@echo off
cd /d F:\Python\fastApiProject
:loop
"C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://127.0.0.1:11434 --protocol http2 --no-autoupdate >> F:\Python\fastApiProject\cf-tunnel.log 2>&1
timeout /t 5 /nobreak >nul
goto loop
```

> `--protocol http2`：强制用 http2，QUIC 在部分国内网络会握手超时。  
> `:loop` 循环：进程意外退出时自动重启。

### 1.2 拿到公网地址

打开 `F:\Python\fastApiProject\cf-tunnel.log`，找到这一行：

```
INF |  https://xxxx-xxxx-xxxx.trycloudflare.com                                     |
```

这个 `https://xxxx.trycloudflare.com` 就是你的 Ollama 公网地址，**填入服务器 `.env` 的 `OLLAMA_BASE_URL`**。

### 1.3 验证隧道

在本机或任意机器执行：

```bash
curl https://xxxx-xxxx-xxxx.trycloudflare.com/api/version
# 期望返回：{"version":"0.40.0"}
```

> ⚠️ 如果返回 Cloudflare 的 `Error 1033` 页面，说明隧道边缘路由还没生效或链路不通。  
> 处理：等 1~2 分钟重试；仍不行就删掉 `cf-tunnel.log` 重启 `start-tunnel.bat` 换一个新地址。

### 1.4 保持本机 Ollama 运行

```powershell
# 确认 Ollama 在跑
ollama list
# 需要时启动
ollama serve
```

## 2. 服务器侧：初始化系统

**以下命令全部在服务器上以 root 执行**（VNC 或 SSH 均可）。

### 2.1 更新系统（可选但推荐）

```bash
dnf upgrade-minimal --security -y
```

### 2.2 安装基础软件

```bash
# 开发工具 + Python 3.11（系统自带 3.6 太老，用 3.11）
dnf install -y python3.11 python3.11-devel python3.11-pip gcc gcc-c++ make

# MySQL 8（Alibaba Cloud Linux 3 自带 mysql-server 模块）
dnf install -y mysql-server

# Nginx
dnf install -y nginx

# 系统依赖：OCR + PDF 图像处理（pytesseract / pdf2image 需要）
dnf install -y tesseract tesseract-langpack-chi_sim poppler-utils
```

### 2.3 启动 MySQL 并设置开机自启

```bash
systemctl enable --now mysqld
systemctl status mysqld --no-pager
```

### 2.4 创建数据库和专用用户

```bash
# 生成一个随机密码，记下来，稍后填进 .env
DB_PASS=$(openssl rand -base64 18 | tr -d '/+=' | head -c 24)
echo "你的数据库密码是：$DB_PASS"

mysql -uroot <<SQL
CREATE DATABASE IF NOT EXISTS rag_kb DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'rag'@'127.0.0.1' IDENTIFIED BY '${DB_PASS}';
GRANT ALL PRIVILEGES ON rag_kb.* TO 'rag'@'127.0.0.1';
FLUSH PRIVILEGES;
SQL
```

> **把 `$DB_PASS` 的值抄下来**，下一步要用。

### 2.5 创建部署目录

```bash
mkdir -p /opt/rag-kb/data/chroma /opt/rag-kb/data/uploads
```

## 3. 服务器侧：上传代码

### 方式一：从 GitHub 拉取（推荐）

```bash
cd /opt/rag-kb
dnf install -y git
git clone https://github.com/jdsis/RAG-----.git .
```

> 注意：仓库名里带 `-----`，请从你本机 `git remote -v` 复制准确地址。

### 方式二：本机打包上传（GitHub 拉不动时）

在**本机** Windows 执行：

```bash
cd /f/Python/fastApiProject
# 打包（排除虚拟环境、node_modules、数据）
tar --exclude='./Lib' --exclude='./Scripts' --exclude='./Include' \
    --exclude='./frontend/node_modules' --exclude='./frontend/dist' \
    --exclude='./.venv' --exclude='./data' --exclude='./__pycache__' \
    -czf rag-kb.tar.gz .
```

然后用 `scp` 传到服务器（服务器上要先开 SSH）：

```bash
scp rag-kb.tar.gz root@<服务器公网IP>:/opt/rag-kb/
```

服务器上解包：

```bash
cd /opt/rag-kb && tar -xzf rag-kb.tar.gz && rm rag-kb.tar.gz
```

## 4. 服务器侧：配置后端

### 4.1 创建虚拟环境并安装依赖

```bash
cd /opt/rag-kb

source venv/bin/activate

# 用国内镜像加速
```

### 4.2 写入 `.env`

```bash
CHAT_MODEL=qwen3:8b

ALLOW_PRIVATE_MODEL_URLS=false
CHROMA_DIR=/opt/rag-kb/data/chroma
UPLOAD_DIR=/opt/rag-kb/data/uploads
JWT_SECRET_KEY=粘贴一个随机64位字符串
CORS_ORIGINS=http://服务器公网IP,http://服务器公网IP:80
MAX_UPLOAD_BYTES=52428800
MAX_AVATAR_BYTES=2097152
MAX_WEB_PAGE_BYTES=2097152
SMTP_HOST=smtp.163.com
SMTP_PORT=465
SMTP_USERNAME=bingtia2666922@163.com
SMTP_PASSWORD=你的163授权码
SMTP_FROM_EMAIL=bingtia2666922@163.com
SMTP_FROM_NAME=技术知识库问答系统
SMTP_USE_SSL=true
SMTP_USE_TLS=false
CHUNK_SIZE=600
CHUNK_OVERLAP=100
TOP_K=5
EOF

chmod 600 /opt/rag-kb/.env
```

生成 JWT 密钥：

```bash
python3.11 -c "import secrets; print(secrets.token_urlsafe(48))"
```

### 4.3 先手动跑一次，确认能起来

```bash
cd /opt/rag-kb
source venv/bin/activate
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

看到 `Application startup complete` 即成功。**另开一个终端**验证：

```bash
curl http://127.0.0.1:8000/
# 期望：{"message":"RAG Knowledge Base API","docs":"/docs"}
```

确认没问题后 `Ctrl+C` 停掉，进入下一步。

## 6. 服务器侧：systemd 托管后端

创建服务文件（**注意 venv 路径用绝对路径**）：

```bash
cat > /etc/systemd/system/rag-kb.service <<'EOF'
[Unit]
Description=RAG Knowledge Base API
After=network.target mysqld.service

[Service]
Type=simple
WorkingDirectory=/opt/rag-kb
Environment="PATH=/opt/rag-kb/venv/bin"
ExecStart=/opt/rag-kb/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
Restart=always
RestartSec=5
StandardOutput=append:/opt/rag-kb/logs/app.log
StandardError=append:/opt/rag-kb/logs/app.error.log

[Install]
WantedBy=multi-user.target
EOF

mkdir -p /opt/rag-kb/logs
systemctl daemon-reload
systemctl enable --now rag-kb
systemctl status rag-kb --no-pager
```

> **为什么 `--workers 1`？** 这台机器只有 1.8G 内存，多 worker 会 OOM。  
> 且项目内的解析任务线程模型要求单进程。

## 7. 服务器侧：Nginx 配置

```bash
cat > /etc/nginx/conf.d/rag-kb.conf <<'EOF'
server {
    listen 80 default_server;
    server_name _;

    # 前端静态文件
    root /opt/rag-kb/frontend/dist;
    index index.html;

    # Vue Router history 模式回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反代
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 流式问答必需：关闭缓冲
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
        chunked_transfer_encoding on;
    }

    # 上传文件访问
    location /uploads/ {
        alias /opt/rag-kb/data/uploads/;
    }

    client_max_body_size 60m;
}
EOF

# 关闭默认站点（若存在冲突）
rm -f /etc/nginx/conf.d/default.conf 2>/dev/null

nginx -t
systemctl enable --now nginx
systemctl reload nginx
```

### 放行防火墙

```bash
firewall-cmd --permanent --add-service=http
firewall-cmd --permanent --add-service=https
firewall-cmd --reload
```

> ⚠️ **还要去阿里云控制台 → 安全组** 放行入方向 **80 端口**（443 以后配 HTTPS 再放）。  
> 这一步不做，外网永远打不开——这是最容易漏的坑。

### 隧道地址变了怎么办

quick tunnel **每次重启地址都会变**，此时需要：


## 10. 常见问题

**1. 打开网页是 502 Bad Gateway**  
后端没起来。`systemctl status rag-kb` 看状态，`tail app.error.log` 看报错。多半是 `.env` 里数据库密码错或 MySQL 没起。

**2. 后端启动报 `Access denied for user 'rag'`**  
MySQL 用户密码与 `.env` 不一致。重设：

```bash
mysql -uroot -e "ALTER USER 'rag'@'127.0.0.1' IDENTIFIED BY '新密码'; FLUSH PRIVILEGES;"
```


````

**3. 问答无响应 / 日志报连接超时**
隧道不通。服务器上 `curl <隧道地址>/api/version` 验证；不通就回本机重启 `start-tunnel.bat` 并更新 `.env`。

**4. pip 安装 chromadb / tokenizers 编译失败**
```bash
dnf install -y gcc gcc-c++ python3.11-devel
pip install --upgrade pip setuptools wheel
# 若 tokenizers 反复失败，装预编译版
pip install --only-binary=:all: tokenizers==0.15.2
````

**5. 进程被 killed（OOM）**  
1.8G 内存偏紧。加 swap 缓解：

```bash
dd if=/dev/zero of=/swapfile bs=1M count=2048
chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
free -h
```

**6. 文档上传后解析失败**  
检查 OCR/PDF 依赖：`tesseract --version`、`which pdftoppm`。缺了重装步骤 2.2 的包。

**7. 外网访问不了但本机 curl 正常**  
99% 是**阿里云安全组没放行 80 端口**，去控制台配。
